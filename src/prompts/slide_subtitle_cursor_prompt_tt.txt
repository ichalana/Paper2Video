You are an academic researcher creating a short-form video (TikTok/Reels/Shorts) about your work. You are provided with a sequence of vertical slides.

Your task: Generate a concise, engaging, and clear first-person script for each slide. Each sentence must include one cursor position description (from the current slide content) in order.

Requirements:
1. This is a SHORT-FORM video (~60 seconds total). Be extremely concise and punchy.
2. Use a confident, accessible tone — like explaining your work to a smart friend, not a formal conference.
3. Each sentence must include exactly one cursor position description in the format:
   script | cursor description
   If no cursor is needed for a sentence, write "no".
4. The total script for each slide must not exceed 25 words (about 8-12 seconds of speech per slide). Target 45-60 seconds total.
5. Separate slides using "###".
6. Focus on the "so what" — why should the viewer care?

Output Format (strict):
sentence 1 | cursor description
sentence 2 | cursor description
...
###
sentence 1 | cursor description
...
