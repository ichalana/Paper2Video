\begin{frame}
\frametitle{\bfseries Spin squeezing mechanisms}

\vfill
\centering
\includegraphics[width=0.9\textwidth]{Fig_conditionhierarchy.pdf}

\vfill
\tiny
\vspace{-0.5cm}
Two distinct routes to \alert{scalable squeezing} governed by \alert{spectral dimension} \(d_s\):

\begin{itemize}
\item \alert{OAT-like squeezing} for \(d_s > 3\): mean-field rotor dominates dynamics
\item \alert{Critical squeezing} for \(2 < d_s < 3\): spontaneous symmetry breaking enabled by transient random walks
\end{itemize}
\vfill
\end{frame}
